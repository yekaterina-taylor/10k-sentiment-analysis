# 10-K Financial & Sentiment Analysis

A website for exploring ten years of SEC 10-K data for a company: financial statements,
liquidity / solvency / efficiency / profitability ratios, stock prices, and
Loughran-McDonald sentiment analysis of the MD&A section.

## Pages (planned)

- **Apple (AAPL)**
- **NVIDIA (NVDA)**
- **Any company**: enter a ticker to run the analysis
